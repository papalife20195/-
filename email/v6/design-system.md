# КуулКлевер · кисломолочные продукты — V6 design system

**Задача письма:** привести читателя в каталог кисломолочных продуктов через понятный оффер «–15% от 3 штук» и помочь быстро выбрать категорию под конкретный сценарий дня.

## Направление
**Natural grocery editorial**: спокойная редакционная композиция, настоящие продуктовые фото, белое пространство, один сильный CTA. Не dashboard, не SaaS-карточки, не lifestyle-коллаж.

## Токены

| Роль | Значение | Применение |
| --- | --- | --- |
| Paper | `#FBFAF7` | основной фон |
| Ink | `#034D75` | брендовый синий, заголовки, ссылки |
| Text | `#213E45` | основной текст |
| Muted | `#597076` | пояснения, юридический текст |
| Rule | `#D7E1DF` | тонкие разделители |
| Accent | `#75BD20` | единственный акцент: CTA, номера, скидка |

## Типографика

- Display: Georgia / Times New Roman — только headline и редакционные акценты.
- Text/UI: Arial / Helvetica — для надёжной поддержки почтовыми клиентами.
- Цены используют tabular numerals.

## Правила email

- 600 px, table layout, без JS и без критичной анимации.
- Одна primary-CTA семантика: «Выбрать продукты».
- Вторичные действия — текстовые ссылки.
- До production: заменить GitHub RAW на CDN/ESP, актуализировать товары, условия, UTM и ссылку отписки.
