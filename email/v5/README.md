# V5 — editorial HTML email

**Задача:** привести читателя в каталог кисломолочных продуктов через один главный оффер и понятную, неброскую продуктовую навигацию.

## Применённый дизайн-подход

- Направление: **Soft / Warm editorial** — подходит еде и lifestyle, при этом сохранены фирменные синий и лаймовый КуулКлевер.
- Один главный акцент: лаймовый. Глубокий синий — фирменный ink/навигационный цвет, а не второй «акцент».
- Одна доминанта: асимметричный hero с био-йогуртами и оффером.
- Товарные категории сначала даны как компактный индекс, а затем раскрыты несколькими разными редакционными модулями. Это намеренно избегает пяти одинаковых карточек подряд.
- Нет бесконечных анимаций: для email они не добавляют пользы и плохо поддерживаются. Есть только безопасные hover-состояния там, где их поддерживает клиент.
