# HTML-письмо «Кисломолочные продукты» — V4

Главный файл: `kuulklever_yogurts_v4.html`.

## Что уже реализовано

- адаптивный email шириной 600 px, таблицы для совместимости с Outlook;
- мобильное перестроение товарных карточек;
- CTA-кнопки, hover-состояния и одна ненавязчивая анимация свечения у hero-CTA;
- fallback: если анимация не поддерживается (например, Outlook), кнопка остаётся обычной статичной;
- изображения, подготовленные для письма, в `assets/`;
- фирменные иконки из исходного `иконки.png`, нарезанные на отдельные PNG: `discount-15.png`, `sun.png`, `gift.png`, `telegram.png`;
- бейдж скидки, солнце и подарок уже интегрированы в hero, вводный и промоблок;
- актуальная ссылка на кисломолочный каталог КуулКлевер вставлена как базовая ссылка для кнопок.

## Обязательно заменить перед отправкой

1. **Изображения.** В HTML сейчас стоят GitHub RAW-ссылки для предпросмотра. Для реальной отправки загрузите все файлы из `assets/` на CDN или в хранилище ESP и замените общий префикс URL в `src`.
2. **Ссылки.** Нужны прямые URL товаров, категорий и статей, а также UTM-метки кампании. Сейчас карточки ведут в общий кисломолочный каталог.
3. **Юридический блок.** Замените `{{unsubscribe_url}}` на системную переменную используемого сервиса рассылки и добавьте обязательные реквизиты/ссылки согласно правилам компании.
4. **Промо.** Цены, скидки и пороги покупки перенесены из исходного ТЗ, поэтому их необходимо подтвердить до отправки.

## Тестирование

До запуска проверьте письмо в Gmail (web/mobile), Mail.ru, Яндекс Почте, Outlook Windows, Outlook web и Apple Mail. Для production желательно использовать Litmus или Email on Acid.
